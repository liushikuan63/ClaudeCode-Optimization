# 并行任务所有权

- 按文件/子系统标明每单元的 owned paths、只读依赖和前置依赖；同一文件单写者，依赖项按波次串行。指定唯一集成者和集成后的验收范围。
- 并行只选互相独立、边界明确且结果能分别审阅的工作；共享配置、迁移顺序、全局规则或跨文件契约需先协调归属。保护已有未提交改动，不把审阅预演称作集成或测试通过。
- 使用 Claude 原生 session/agent/worktree 能力时遵守当前宿主流程、用户范围与工作区状态。Git worktree 共享 Git 配置、对象和引用，不是安全沙箱；不得运行会关闭 hooks、绕过签名、静默提交或擅自清理的并行 helper。
- 先汇总各单元实际改动与验证，再由唯一集成者处理冲突并执行全局检查。工具给出的 READY/可合并预判不是实际合并、测试或发布的证据。
