# 性能证据

- 先选与目标相符的指标：延迟分位数、吞吐、CPU/内存、请求/查询数或费用；记录工作负载、正确性条件和基线。
- 基线与候选保持输入、版本、配置、硬件、并发、数据量及缓存/预热状态可比。说明预热与重复次数，保留样本或聚合方法，避免挑选单次最好结果。
- 优化后再运行同一工作负载和正确性检查；正确性、错误率或稳定性退化时不能只报告速度收益。
- 比较观察到的变化与测量噪声；变化落在噪声范围就写“未确认”，同时记录限制，不无限试验或套用其他机器上的固定阈值。
