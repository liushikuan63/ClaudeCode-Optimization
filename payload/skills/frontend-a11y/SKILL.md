# 前端可访问性交互

- 优先原生 button、link、form 控件及正确 label 关联；错误信息与字段关联并暴露错误状态。键盘顺序、可见焦点和实际可操作行为要一致。
- 对话框/模态核开启后的初始焦点、Tab/Shift+Tab 限制、Escape 策略、关闭后焦点回归，以及背景内容是否可交互。`aria-modal` 本身不会实现焦点管理或背景隔离。
- 动效需尊重 reduced-motion，并让重要内容不依赖动画或自动播放才能看到；检查暂停控制、循环边界、主题下实际 computed style 与内容布局。
- 在真实组件及相关视口用键盘和辅助属性检查关键路径。只报告已检查的组件、状态与缺口，不从局部抽查推断全站或标准级合规。
