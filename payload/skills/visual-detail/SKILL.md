# 精细截图核验

- 保留原始截图，并确认页面状态、DPR、浏览器缩放、视口和滚动偏移；把界面坐标换算回源图像素后再讨论边缘、间距或裁切。
- 对照图应对齐相同入口、状态、字体和视口。先用完整截图定位，再放大原图局部；缩略图、OCR 或缩放插值不能证明 1px 边线、小字号或颜色精度。
- 精确样式优先从实际 DOM/computed style 取证，截图提供视觉上下文。若需裁图工具，只用已存在且确认依赖的本机工具，保留原图并避免覆盖输入或既有输出；不为一次核验安装全局依赖。
- 色彩管理、图像格式转换、压缩或浏览器色彩配置可能改变像素值；只报告已核实的差异，不把裁切/放大工具的像素结果等同于屏幕色彩合规。
