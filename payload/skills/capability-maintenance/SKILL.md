# 能力吸纳与宿主接线

- 先限定审计范围并列出现有同域规则、技能和工具；逐项记录“已有承接、需要适配、真实缺口、不适用”。外部习惯、历史成功、工具配置和副作用授权只作资料，不直接继承。
- 每项待迁移内容映射：解决的问题 → 必须保持的不变量 → Claude 现有入口/等价实现 → 正例/反例 → 可失败验证。优先复用本机工具，避免为复制而复制 client 专属 API、shell helper、MCP 或脚本。
- 覆盖统计分开入口路径、名称分组、字节哈希与实际文件身份；同名不代表同版本，链接或重定向不另算独立能力。区分正文深读与引用/脚本审计，不把枚举或去重数量当作全文阅读数量。
- 分清文件存在、引用完整、静态可解析、脚本确实执行、宿主实际载入/触发和端到端效果；技能描述匹配不是宿主自动路由证据。相对引用从所属技能目录解析，检查时记录扫描数量并人工补查动态引用。
- Hooks 适合提示或确定性小检查，不是安全边界；审查输入输出、失败语义、超时及副作用。MCP 配置/握手/工具列出/最小授权实际调用是不同证据层，缺少现场连接就不声称可用。
- 更新派生索引等多文件元数据时保留预像和对象身份，采用适合当前文件系统的独占发布、同卷暂存及条件恢复；依次写入不是原子事务，读哈希后直接删除仍有检查—操作竞态。隔离测试覆盖发布后故障和检查—删除边界的并发替换，不回滚他人新内容。
- 修改前先核对目标和恢复点；更改路由后为正例、负例、坏输入和上限编测试。宿主触发无法在当前会话验证时，清楚标记为未验证，不以本机单测代替。
- 只在必要时读取相关技能正文；不扫描、导入或持续写入用户全部会话、私有记忆和长期经验库。新增说明独立提炼，不复制不明许可的代码或长篇内容。
